# Stash relay

Маленький сервер (Cloudflare Worker) для общего Telegram-бота Stash. Токен бота хранится только здесь.
Каждая копия Stash привязывается кнопкой «Привязать Telegram» и получает сообщения своего владельца.

## Развёртывание (один раз)

Нужен бесплатный аккаунт Cloudflare и токен бота от @BotFather. Все команды выполняются в папке `relay`.

1. Войти в Cloudflare (откроется браузер):

   ```bash
   npx wrangler login
   ```

2. Выложить сервер. В конце команда напечатает адрес вида `https://stash-relay.<имя>.workers.dev`:

   ```bash
   npx wrangler deploy
   ```

3. Сохранить токен бота на сервере (команда спросит его и не покажет на экране):

   ```bash
   npx wrangler secret put BOT_TOKEN
   ```

4. Один раз открыть в браузере `https://stash-relay.<имя>.workers.dev/setup`. Страница ответит
   «Готово: бот @… подключён». С этого момента Telegram шлёт сообщения бота на сервер.

5. Прописать адрес сервера в Stash: константа `RELAY_URL` в `src/main/telegram.ts`
   (или переменная окружения `STASH_RELAY_URL` для проверки).

Бот, подключённый к серверу, больше нельзя использовать в Stash «по токену»: Telegram отдаёт сообщения
только в одно место.

## Проверка

```bash
npx wrangler dev --port 8799      # локальный сервер, токен и адрес Telegram берутся из .dev.vars
node test/mock.mjs                # сервер против поддельного Telegram
node test/e2e-stash.mjs           # настоящий Stash (тестовый профиль) против локального сервера
```

`.dev.vars` для тестов:

```
BOT_TOKEN="123:TEST"
TG_API="http://127.0.0.1:8798"
```

## Что хранит сервер

- Привязку «аккаунт Telegram → копия Stash» (по хэшу ключа; сам ключ сервер не хранит).
- Недоставленные сообщения, пока Stash выключен, не дольше 48 часов.
- Файлы не хранятся: сервер передаёт их из Telegram в Stash на лету и только владельцу.
