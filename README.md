# Stash

Личный менеджер референсов для Windows: картинки и видео в одной библиотеке, с тегами, папками и мудбордами.

## Возможности

- Библиотека в обычной папке (`*.stash`): файлы, превью и база лежат рядом, их легко переносить и бэкапить.
- Теги, папки, рейтинг, заметки, поиск по цвету и по похожим изображениям.
- Автотеги локальной моделью CLIP — без отправки файлов в интернет.
- Видеоплеер с покадровой перемоткой, скриншотом кадра и обрезкой фрагмента.
- Конвертер форматов для изображений и видео, раскадровка видео.
- Мудборды на бесконечном холсте с экспортом.
- Расширение для браузера (папка `extension/`): сохранение картинок и видео с сайтов.
- Расширения в формате `.stashplugin`.
- Автообновление установленной версии.

## Разработка

Нужен Node.js 22+.

```bash
npm install
npm run dev        # запуск с горячей перезагрузкой
npm run typecheck  # проверка типов
```

## Сборка установщика

```bash
npm run dist       # release/Stash-Setup-<версия>.exe
npm run release    # то же + публикация релиза на GitHub (нужен GH_TOKEN)
```

Перед выпуском новой версии поднимите `version` в `package.json`.
